# Numlex DMG Installer Artwork

Styled, Retina-aware background for the Numlex drag-to-Applications DMG.
The background is pure decorative canvas: it contains **no** window chrome,
traffic lights, title bar, or rim — the real native Finder window provides
all chrome. No third-party artwork is used or referenced.

## Files

| File | Size | Purpose |
| --- | --- | --- |
| `numlex-tagline.png` | 506×122 px (1×), RGBA, sRGB | User-supplied tagline asset: `Think freely. We’ll do the math.` with purple/blue word accents. Copied byte-exact from the user's source; the committed file is the single source of truth for the tagline pixels. |
| `NumlexDMGBackground.png` | 800×450 px, 72 dpi (1×) | Finder content-area background, sRGB, 8-bpc, alpha. |
| `NumlexDMGBackground@2x.png` | 1600×900 px, **144 dpi** (2×) | Retina representation of the same canvas. Tagged 144 dpi via `sips -s dpiWidth 144 -s dpiHeight 144` — this Finder honors the dpi tag and renders it at the correct 800×450 pt scale with Retina detail (proven; a raw untagged @2x renders 2× oversized/cropped, and a multirep TIFF is silently ignored). |

Both background PNGs are generated by `Scripts/generate-dmg-background.swift`
(built-in AppKit/CoreGraphics only — no external dependencies). Re-generate
with:

```
swift Scripts/generate-dmg-background.swift \
    Assets/DMG/numlex-tagline.png \
    Assets/DMG/NumlexDMGBackground.png \
    "Assets/DMG/NumlexDMGBackground@2x.png"
sips -s dpiWidth 144 -s dpiHeight 144 "Assets/DMG/NumlexDMGBackground@2x.png"
```

The generator is deterministic: identical inputs produce identical pixels.
The 1× tagline PNG is upscaled with high-quality interpolation for the 2×
canvas; all vector elements (gradient, glows, arrow, footer text) are
re-rendered natively at 2×.

## Canvas specification

Finder content canvas: **800×450 pt** (1600×900 px @2×). All coordinates
below are in points, origin at the **top-left** of the content area.

| Element | Specification |
| --- | --- |
| Background | Dark hero `#090B11` (top) → `#101625` (60%) → transition `#5A6579` (71%) → clean light shelf `#C9D1DD` (79%) → `#B7BFCC` (bottom). The shelf carries the Finder icon labels (this Finder renders icon labels black with any background picture set — white-on-dark is unachievable) and the footer with high contrast |
| Purple glow (behind app) | Radial, centered **(220, 285)**, radius 200, `#8B5CF6` at 20% alpha → 0 |
| Blue glow (behind Applications) | Radial, centered **(580, 285)**, radius 200, `#3B82F6` at 20% alpha → 0 |
| Tagline | `numlex-tagline.png` drawn **400 pt** wide (x 200–600, aspect 506:122 kept → 400×96.4), top edge **y = 42** (safe region, no icon overlap); exact supplied pixels |
| Arrow | Thin (2.2 pt) rounded shaft, purple→blue gradient, x 312→452 at **y = 285**; solid blue (`#3B82F6`) triangular head, tip at x = 488. Pure vector — no cursor, no fake icons |
| Footer | `Drag Numlex to Applications to install`, SF System 15 pt medium, dark slate `#39404B` (for the light shelf), centered, glyph rows ≈ **378–393** (fully inside with ~57 pt bottom margin) |
| Icon slots (Finder, not painted) | `Numlex.app` centered **(220, 285)**, `Applications` centered **(580, 285)**, icon size **128 pt** — set by `Scripts/configure-dmg-finder.sh`, see below |

The glows sit behind the real Finder icons; the arrow joins the gap between
the two icon slots. The background extends past all edges with calm
gradient, so shorter Finder window heights reveal continued background
instead of blank bands.

## Building the DMG

Production builds use only macOS-native tools (no third-party DMG tools):

```
Scripts/build-dmg.sh [release]          # or NUMLEX_USE_BUILT_APP=1 to reuse .build/Numlex.app
```

The script:
1. Runs the generator above (artwork is always up to date).
2. Creates a read-write HFS+ image, attaches it at the default `/Volumes`
   location (so Finder tracks it), copies the app + `Applications` symlink,
   places the backgrounds in `.background/` (1× as `background.png`,
   144-dpi-tagged 2× as `background@2x.png`), pins the 2× file as the
   Finder background picture (correct pt scale + Retina detail), sets
   the dark icon-view background color (drives white Finder labels),
   hides support items (Finder-invisible + off-canvas), applies the
   volume icon (`AppIcon.icns`) and a strict Finder `.DS_Store` layout
   (exact positions, verified by readback — no default-grid fallback),
   then detaches and converts to a read-only UDZO
   `dist/Numlex-<VERSION>-macOS-<arch>.dmg`.
3. Finder window layout is applied by `Scripts/configure-dmg-finder.sh`
   (real Finder Apple events only; no synthetic pointer/keyboard input).
   On a machine without a GUI Finder session the build fails clearly,
   unless `NUMLEX_PLAIN_DMG=1` is set to emit an unstyled DMG (loudly
   labeled as plain in its output name suffix).

## DMG Canvas (optional manual re-creation)

The committed PNGs import directly into DMG Canvas 4.x for visual editing:
Canvas size 800×450 pt (set "Retina: 2× pixels" for the @2x file), then
import `NumlexDMGBackground.png` / `@2x` as the background layer. Because
the DMG Canvas CLI on this machine is unusable (Team-ID framework
mismatch), Canvas is for *manual inspection only* — production packaging
never depends on it. If you edit in Canvas, export 1×/2× PNGs at the
sizes above, replace the generated files, and re-run
`Scripts/validate-dmg.sh`.
