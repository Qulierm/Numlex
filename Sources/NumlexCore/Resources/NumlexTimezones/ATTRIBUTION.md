# Bundled timezone data — sources and licenses

The files in this directory are GENERATED by
`Scripts/generate-timezone-data.py` (reproducible; run it to regenerate).
The app never fetches any of this at runtime.

| Resource | Source | License |
| --- | --- | --- |
| `iana-zones.tsv` | IANA Time Zone Database (`zone1970.tab`, `backward`), <https://www.iana.org/time-zones> | Public domain |
| `cities.tsv` | GeoNames `cities15000` (cities with population >= 100,000), <https://www.geonames.org> | CC BY 4.0 |
| `countries.tsv` | derived from the GeoNames capital entries and the IANA country codes | CC BY 4.0 / public domain |
| `airports.tsv` | airportsdata, <https://github.com/mborsetti/airportsdata> | MIT |

`sources.json` pins the exact source URLs together with the SHA-256 of each
downloaded file, the IANA tzdata release, the per-resource SHA-256 and the row
counts. `TimezoneCatalog` verifies every resource hash before use and fails
closed on any mismatch.

GeoNames attribution (CC BY 4.0): "This product includes data from GeoNames
(<https://www.geonames.org>), licensed under CC BY 4.0."
